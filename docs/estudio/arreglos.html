Arreglo de obras existentes para una formación distinta de la original, con decisiones propias de escritura: registro, densidad, articulación, distribución del material y equilibrio entre voces.

El trabajo parte de una conversación sobre el resultado deseado. No es lo mismo un arreglo para coro infantil que para coro mixto amateur, ni un arreglo para ensamble de guitarras que para orquesta de cuerdas: cada formación impone restricciones de tesitura, lectura y tiempo de ensayo.

Se entrega partitura general y partes individuales, en PDF para lectura y en archivo editable para correcciones. Incluye una revisión posterior al primer ensayo.

Arreglos publicados en video: seis registros en vivo.

Arranging existing works for a different body than the original, with decisions that belong to writing: register, density, articulation, distribution of the material and balance between voices.

The work starts from a conversation about the result wanted. An arrangement for a children's choir is not the same as one for an amateur mixed choir, nor one for a guitar ensemble the same as one for a string orchestra: every ensemble imposes limits on tessitura, sight-reading and rehearsal time.

The delivery is a full score and individual parts, in PDF for reading and in an editable file for corrections. It includes a revision after the first rehearsal.

Arrangements published on video: six live recordings.
